# Landlord Management System (LMS)

A simple, professional, lightweight landlord management system for Windows, designed around the rental practices commonly used by small landlords in Nepal.

## Status

**Planning:** Complete and locked  
**Current implementation phase:** Release 0.0 — Repository Initialization  
**Target:** Windows desktop first; FastAPI/mobile later

## Technology

- Python 3.13+
- PySide6
- PostgreSQL
- SQLAlchemy 2.x
- Alembic
- FastAPI (future API)
- ReportLab
- PyInstaller
- Git/GitHub
